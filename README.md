Este repositorio contiene una aplicación web sencilla desarrollada para una práctica universitaria. 
Su objetivo principal es aprender a usar TypeScript, Vite y conectar una página web con una API externa para mostrar datos reales en una tabla.

Para lograrlo, el proyecto utiliza tecnologías como TypeScript para un código más seguro y ordenado, HTML y CSS 
(con la fuente Lexend) para el diseño visual, y la API pública de JSONPlaceholder para extraer la lista de álbumes. 
Todo está organizado en una estructura limpia de carpetas que incluye el código fuente, las interfaces y la configuración necesaria.

Si quieres probarlo en tu computadora, solo tienes que clonar el repositorio, abrir la terminal en la carpeta del proyecto, 
escribir npm install para instalar lo necesario y luego ejecutar npm run dev. Por último, solo abre el enlace que te aparecerá en 
pantalla para ver la aplicación funcionando.
